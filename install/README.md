# Codex娘 · 独立桌面伙伴

推荐直接打开 Release 中的独立 EXE，素材已经内置。点击 **导入到 Codex Pet → 导入**，再去 Codex **设置 → 宠物 → 刷新** 中选择 **Codex娘**。原生宠物只显示动画，额度仍在本程序的独立窗口中显示。

点额度卡片右上角 **−** 可隐藏卡片并保留宠物；双击宠物或右键选择 **显示额度卡片** 恢复。程序会记住隐藏状态。

完整 ZIP 安装方式：

1. 将 ZIP **完整解压**到一个文件夹。
2. 双击 **Install.cmd**，安装后会自动打开额度宠物。
3. 她旁边会显示短期 / 每周等额度窗口的 **剩余百分比** 和 **重置倒计时**。数据来自本机 Codex CLI 登录的账户，每分钟刷新一次。

拖动宠物或卡片可以移动窗口；按住头部小幅来回轻抚，点击身体戳一戳；双击显示或隐藏额度卡片，点击 ↻ 刷新。右键调整大小、切换置顶、导入到 Codex 或退出。手动刷新间隔至少十秒。断网或读取失败时会保留并标记旧数据；缺失数据不会当成 0%。

## 登录与数据

需要 Windows、桌面端附带的 codex.exe（或 PATH 上的 Codex CLI）和已登录的 ChatGPT 账户。若显示读取失败，先检查网络，并在终端运行 codex login 登录对应账户。CLI 和桌面端可能使用不同账户，本工具显示的是 **CLI 当前登录账户** 的 Codex 额度，并非 API 余额。

若找不到 CLI，可设置环境变量 CODEX_GIRL_CODEX_EXE 为 codex.exe 的绝对路径，再重新打开额度宠物。额度功能不自动下载 CLI，不读取或复制令牌文件，不保存额度响应、邮箱或账户 ID。额度功能只通过官方 App Server 发送初始化和 account/rateLimits/read 请求，不发起模型对话。App Server 自身会使用 Codex 正常的登录和运行状态目录。

本机不联网也能完成安装；实时额度读取需要网络。无需管理员权限、Python 或 Git。

## 与原生宠物的关系

额度版是使用相同动画素材的**独立悬浮窗口**。原生宠物素材清单没有实时文字插槽，额度版不会接管原生聊天入口、任务状态或鼠标视线。它不会自动隐藏原生宠物；若出现两只，可从原生宠物菜单隐藏原生窗口。

原生动画也会一并安装。需要纯原生宠物时，关闭额度窗口，再到桌面端 **设置 → 宠物 → 刷新** 选择 **Codex娘**；必要时重启桌面端，输入 /pet 显示。需要支持 v2 自定义宠物的桌面端。本地安装不会自动同步到网页账户。

## 安装、升级与卸载

默认安装到 %USERPROFILE%/.codex/pets/codex-girl；配置了 CODEX_HOME 时使用该目录的 pets/codex-girl。只更新此宠物的清单、精灵图、额度程序与启动器。升级前自动备份已有文件到 pet-backups，重复安装同一版本不重复备份。升级前请退出已运行的额度窗口，再运行新版安装器。

下次启动可双击解压目录或安装目录中的 Start-Quota.cmd，也可直接运行 quota/CodexGirlQuota.exe。需要 Windows 的 .NET Framework 4.8。

位置、大小和置顶偏好保存在 %LOCALAPPDATA%/CodexGirlQuota/settings.json。开机启动默认关闭，可在右键菜单手动启用。解压后直接双击 Start-Quota.cmd 也可运行，不必安装。

需要只安装、不启动或使用自定义目录时，可运行 powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -CodexDirectory "D:\MyCodex"。直接运行 Install.ps1 只复制文件；Install.cmd 会在成功后启动额度宠物。

卸载前如果启用过开机启动，请在菜单关闭。卸载时退出额度窗口并在设置中切换到其他宠物，然后删除 codex-girl 安装文件夹。备份及偏好设置可自行保留。

接口说明见 [官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)，原生宠物说明见 [OpenAI Pets 文档](https://learn.chatgpt.com/docs/pets)。

## 桌宠互动

按住头部小幅轻抚，拖动身体移动，单击身体戳一戳。右键 **互动** 有喂食、夸夸、逗逗、跳跃、手柄游戏和读书；心情值 0–100，连续三次相同食物会嫌腻。**活动模式** 可切换原地陪伴、散步和跟随鼠标；闲置 90 秒进入瞌睡，互动唤醒。贴边可托腮或倒挂。现已配有摸头、进食、开心、生气、嫌腻、闭眼休眠六组专属动画，每组四帧。五种食物各有四帧专属动作：小鱼干咬嚼、蛋糕叉取、棒棒糖含糖、团子串签、钻石吸收光芒。换食物会切换对应画面，连续三次同款仍会嫌腻。散步和跟随使用左右行走帧；移动、呼吸和拖拽抖动参考大肥鱼的动画公式。没有直接使用其角色立绘。

右键可隐藏到托盘、启用鼠标穿透、设置开机启动。双击托盘图标可以恢复位置并解除穿透。穿透每次重新启动默认关闭，防止无法点击。移动模式保存在同目录 desktop.json。

右键 **和她聊天 / AI 设置** 填写兼容 OpenAI 的接口根地址、模型、API Key，保存后发送。发送才会请求你配置的服务，可能产生其 API 费用；最近 40 条消息仅在当前聊天窗口内存中。密钥使用 Windows 当前账户加密保存到 %LOCALAPPDATA%/CodexGirlQuota/chat.json，不能跨用户解密。此聊天功能与 Codex 账户登录、额度读取独立。

天气需要手动输入城市并查询，城市名发送给 wttr.in，不读取定位。系统状态支持 CPU 和内存；GPU 温度显示暂不可用。开机启动开启后会在当前用户的 Run 注册表项写入本 EXE 路径，移动或删除文件前请先关闭。
