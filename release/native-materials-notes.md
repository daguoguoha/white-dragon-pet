# Codex娘 · 原生素材替换版 v1

只替换 Codex 原生 Pet 的图片素材和素材路径，不修改客户端，不运行额外桌宠程序，不新增重复宠物条目。

下载 **Codex-Girl-Native-Materials-v1.zip**，完整解压后双击对应的启动脚本：

| 脚本 | 工作中显示的食物 |
| --- | --- |
| Use-fish.cmd | 小鱼干 |
| Use-cake.cmd | 蛋糕与叉子 |
| Use-lollipop.cmd | 棒棒糖 |
| Use-dango.cmd | 三色团子 |
| Use-diamond.cmd | 钻石，表现为吸收光芒 |

安装后到 Codex **设置 → 宠物 → 刷新**，重新选择 **Codex娘**。需要时先切到其他宠物再切回，以刷新图片缓存。

互动槽显示闭眼歪头的摸头反应，等待槽显示闭眼休息，工作槽显示所选食物动画，失败槽显示抱臂生气。保留原来的待机、移动、跳跃、读书和十六向视线。

这些画面仍由 Codex 的固定状态触发；不会新增喂食菜单、心情系统、触摸检测或睡眠计时器。五种食物通过运行对应脚本替换同一个条目的素材来切换。

素材格式为原生 v2 的 1536×2288，8 列×11 行。已校验有效帧、透明未用槽、v2 中性姿态，以及原有移动和视线帧保持原样。

替换前自动备份到 Codex 的 pet-backups/native-materials-*；原始精灵图、独立 EXE 和偏好设置保持原样，安装失败恢复旧素材。无需管理员权限。默认遵循 CODEX_HOME。

打开压缩包中的 **preview.html** 可预览所有槽位。**Native-Materials-SHA256SUMS.txt** 提供压缩包校验值。

需要完整鼠标互动和菜单的版本，可使用另行发布的 **独立桌宠 v1.3.2**。
