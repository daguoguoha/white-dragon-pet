# 独立桌宠高清原画

这些 PNG 是之前 imagegen 生成的九组原始动作条带的逐字节副本，保留原造型和每一帧，不是把 192×208 原生素材插值放大。绿色是原始透明抠图底色，在独立程序加载时去除并清理轮廓色边。

`desktop-artwork.json` 只含原图 SHA256、裁剪范围和逻辑绘制位置，复用原生版已经校准的共享缩放、脚底基线与跳跃落点，不包含本机路径或账户信息。独立版直接从这些原图渲染到 384×416 的冻结缓存，显示尺寸保持 192×208 DIP；互动和喂食也从原图直接渲染到相同分辨率。

原生 Pet 的 `assets/spritesheet.png` 及导入格式保持不变。
